# DeepSeek 大肥鱼 · Mosaico 1.1.0

桌面继续使用 Coopanion 原有的大肥鱼部件模型。板端使用同一模型导出的动画资源，
保留蓝发、女仆头饰、鲸鳍、尾巴和围裙形象；缺失的动作和表情在这套模型上补齐。
本次没有修改 Cortico Core、Persona、Memory 或电脑操作授权规则。

## 使用

形象格式最低需要桌面 `0.1.0-mosaico.2` 与板端 `1.1.0`；当前桌面修复版为
`0.1.0-mosaico.3`，板端传送回执修复候选为 `1.1.1`。桌面装扮页的「形象」选择「DeepSeek 大肥鱼」，
「配色」选择原版 DeepSeek。配对完成后，桌面同步并校验资源，完成才允许传送。
旧固件会显示升级提示，继续保留当前身体位置。切回 Coo 仍使用兼容的 COO1 资源路径。
固件自带默认 Coo；第一次使用大肥鱼需要联网同步一次，此后板端使用已缓存资源离线互动。

延续当前行为：轻晃只播放动作；倾角触发摔倒；有限动作不被替换；四条边随重力站立；
传送门位于当前站立边的对边；字幕三行分页；TTS 保持关闭，按键语音输入保留。
1.1.0 已保留数据安装，大肥鱼已在实机显示，但传送遇到回执丢失；1.1.1 修复已构建，
尚待安装和实机复验。不能把模拟器结果当作板上结果。具体范围见[验收记录](coopanion-acceptance.md)。

## 帧数与动作

原版为逐帧计算的部件骨骼，并没有固定的 sprite 帧数。桌面仍使用实时骨骼；板端为内存和
1 MiB 缓存约束采用 **36 段、121 个采样帧**，以原版 8 相位行走与当前状态机时长为基准。
位移、旋转、重力换边、门和光效由共享 C 渲染器逐帧合成，不能把采样帧数当作设备帧率。

| 动作组 | 每段采样帧数 | 时间/行为 |
|---|---:|---|
| 待机 | 4 | 3200 ms，最后 128 ms 眨眼 |
| 开心、眨眼、喜欢、害羞、惊讶、生气、难过、困倦、睡眠、晕、被拎、思考、坐下 | 各 2 | 根据动作循环或保持 |
| 走 / 跑 | 各 8 | 667 / 480 ms 循环 |
| 跳 / 摇晃 / 踉跄 | 各 6 | 700 / 1200 / 1500 ms |
| 摔倒 / 爬起 | 各 6 | 800 / 1200 ms；倒地末帧等待稳定条件 |
| 哭泣 / 背身生闷气 | 4 / 3 | 3000 / 4000 ms |
| 倾听 / 播报姿态 | 2 / 4 | 1800 / 1400 ms；播报姿态保留，TTS 关闭 |
| 离开 / 到达 / 落地缓冲 | 6 / 6 / 4 | 950 / 1300 / 650 ms，与现有状态机配合 |
| 委屈、炸毛、得意、撒娇、好奇、雀跃、哭泣、鼓脸 | 各 2 | 扩展表情，支持对话脚本 |

新增脚本表情名：`worried`、`furious`、`smug`、`pleading`、`curious`、`excited`、
`crying`、`pout`、`sulking`。最后一个显示背身立绘，带轻微呼吸和摆动。
不是完整的 3D 转身插值；其他配色暂时保留原部件动作，不使用蓝色背身贴图。
本轮仅对 DeepSeek 原版蓝色完成视觉验收；其他配色按需导出，超过缓存上限会拒绝同步。

## 资源与协议

默认资源：`desktop/coopanion/packages/cortico-world-desktop-pet/web/whale/mosaico-deepseek.bin`。
192 × 216 像素、128 色、967,993 字节；SHA-256：
`52772f4109671406c778a3899b1c88070a7831bff9a98c5f91a70ef753afbdb4`。

COO2 使用小端序，严格检查全部边界，资源上限 1000 KiB，原有 `coo_assets` 分区仍为 1 MiB。
桌面和板端均校验；WSS 分块、限速和 SHA-256 路径保持不变，资源不能挤占动作通道。
首次能力消息声明 `assetFormats: ["COO1", "COO2"]` 后才开始大肥鱼同步。

| 区域 | 格式 |
|---|---|
| 24 字节头 | `COO2`；u16 宽、高、帧数、片段数、调色板数、形象 ID；u32 总长度、保留 0 |
| 每段 12 字节 | u16 ID、起始帧、帧数、时长 ms、循环标记、保留 0 |
| 每帧 12 字节 | u32 数据偏移、长度；u16 基帧、保留 0 |
| 调色板 | 每色 RGB565LE + alpha，共 3 字节 |
| 像素 | LZ4 block；关键帧为调色板索引，差分帧为与前一帧索引的 XOR |

每段首帧必须独立；基帧 `0xFFFF` 表示关键帧，否则只允许同段前一帧。
上限为 512 帧、64 段、每段 32 帧。连续解码复用索引缓存；随机跳转从该段关键帧重建。
解码使用两个 41,472 字节工作缓冲，检查解压长度、偏移、颜色索引和片段覆盖。
板端放大采用带 alpha 的双线性采样，避免透明边缘出现黑边。

## 导出与预览

在 `desktop/coopanion` 目录、锁定依赖已安装后：

```sh
./node_modules/.bin/electron packages/cortico-world-desktop-pet/host/export-whale.cjs /absolute/output/mosaico-deepseek.bin atlas deepseek
pnpm --dir packages/cortico-world-desktop-pet test
```

导出器使用原版 WebGL 部件模型，在隔离页面内以固定 60 Hz 步长推进弹簧，输出 COO2 和同名
`.json` 清单。它不启动用户部署、模型、麦克风或设备连接。默认蓝色资源预编译随桌面交付，
正常同步无需临时渲染全部采样帧。修改角色后需要重新导出并更新对应校验记录。

在桌宠包目录运行 `node examples/whale/serve.mjs 4319`，打开
`http://127.0.0.1:4319/examples/whale/mosaico.html`，可逐项切换原版骨骼动作与新表情。
这是角色预览；板端的重力、位移、传送与字幕应通过官方 GSP 模拟器验收。
共享 C 测试：根目录运行 `python projects/coopanion/tools/test_native.py`。
连续录像工具为 `projects/coopanion/tools/record_whale.py`，需先启动官方模拟器和共享后端，
用 `--input-port`、`--api-port` 指定本机端口，`--output` 指定证据目录。

双端联调沿用[开发说明](coopanion-implementation.md#双端模拟器)。运行桌面测试入口前设置
`COOP_PREVIEW_FIGURE=whale`；支持 `COOP_PREVIEW_DIR`、`COOP_PREVIEW_PORT`、
`COOP_PREVIEW_PET_PORT`、`COOP_PREVIEW_VISUAL_PORT` 和 `COOP_SIM_PORT` 以隔离其他实例。
原生后端的 `COOP_SIM_ASSET_PATH` 必须指向同一预览目录中的 `sim-atlas.bin`。

## 美术来源

原部件和角色出处沿用上游声明：原设「溟月」（上善无形），DeepSeek 女仆装二创参考 ZipZipPipe。
本轮八张参考图用于表情方向：委屈汗滴、笑眼、炸毛、wink、得意、撒娇和好奇等。
保留原版模型的二头身比例和描线，不把不同参考图裁成互不一致的角色帧；原始参考图未发布。

新增 `sulk-back.png` 是 OpenAI 图像生成工具制作的透明背面立绘。输入为原版中性表情渲染与
用户的全身参考图；生成要求如下，原始输出保留于本机，仓库保存用于渲染的同一 PNG：

> 一张完整、透明背景的背身鲸鱼女仆立绘，与原模型保持二头身比例、蓝到青的长发、
> 深蓝女仆裙、白色褶边、头饰、鲸鳍、鲸尾和鞋。角色略低头生闷气，双手垂在两侧，
> 围裙背后有白色蝴蝶结；背面不出现眼睛、鼻子或嘴。呆毛、双脚和尾巴完整留在画内。
> 不要地面、投影、文字或独立装饰符号。

透明边界在运行时读取并归一化到与前视模型一致的尺度；未使用生成工具重画或替换原版全部动作。
